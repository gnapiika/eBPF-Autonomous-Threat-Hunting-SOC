# SOC Dashboard

## Purpose
Build the visualization layer for the eBPF-Powered Autonomous Threat Hunting SOC using Grafana.

## Planned Visualizations
- Total security events
- Critical security events
- Hosts and process activity
- Network connections
- Suspicious processes and alerts
- MITRE ATT&CK techniques
- SOAR response status

## Integration
The dashboard will consume normalized security events and response data through agreed interfaces. Other team members' source files will not be modified as part of dashboard development.
